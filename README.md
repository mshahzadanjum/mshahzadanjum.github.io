# Muhammad Shahzad Anjum — Academic Website

A responsive academic profile website built with plain HTML, CSS, and JavaScript for free hosting on GitHub Pages.

## Publish with GitHub Pages
1. Create a public GitHub repository named exactly `YOURUSERNAME.github.io`.
2. Upload all files from this folder to the repository root (index.html, styles.css, script.js, cv.html, README.md).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Set branch `main` and folder `/ (root)`, then Save.
6. Wait a few minutes and open `https://YOURUSERNAME.github.io`.

## Customize
- `index.html`: profile text, publications, links, and sections.
- `styles.css`: colors, spacing, and design.
- `cv.html`: printable academic CV. Open and select **Print / Save as PDF** to export a PDF.
- Replace/add links to Google Scholar, ResearchGate, personal institutional pages, and publication resources when verified.

## Privacy
The site intentionally omits the residential address and phone number from the source CV. It includes the public-facing email address and ORCID identifier. Confirm that you want those displayed publicly before deployment.
